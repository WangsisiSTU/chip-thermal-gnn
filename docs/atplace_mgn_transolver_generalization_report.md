# ATPlace Case1：MGN、MGN+TRANS 与可归因泛化评测

## 数据与评测协议

- 独立物理案例：96 个，来自 24 个布局 × 4 个功率工况。
- 中网格划分：72/12/12 张 train/val/test 图，布局 ID 完全隔离。
- 细网格评测：12 个已见布局配对案例，以及 12 个未见布局配对案例。
- 中网格节点 4,536–6,348，有向边 25,524–35,926；细网格节点 8,316–10,800，有向边 47,424–61,836。
- 配对检查确认：同一 `physical_case_id` 在中/细网格间保持 layout、功率 profile 和总功率一致。
- 三个模型使用相同训练数据、损失、优化预算和解析全局能量投影；训练种子为 3107/3108/3109。

三套测试分别隔离：

1. 未见布局 / 中网格：只改变布局。
2. 已见布局 / 细网格：保持物理案例不变，只改变网格。
3. 未见布局 / 细网格：布局与网格同时变化。

## 结论

- 未见布局 / 中网格：场 MAE 最低为 MGN+TRANS `0.855 K`；峰温误差最低为 MeshGraphNet `0.312 K`。
- 已见布局 / 细网格：场 MAE 最低为 MGN+TRANS `1.019 K`；峰温误差最低为 MeshGraphNet `0.429 K`。
- 未见布局 / 细网格：场 MAE 最低为 MGN+TRANS `1.057 K`；峰温误差最低为 MeshGraphNet `0.380 K`。
- MGN+TRANS 在三套测试的平均场误差均最低，说明全局物理状态交互对布局变化有效。
- MeshGraphNet 的峰温误差更低且细网格种子方差更小；当前结果不支持用单一指标宣布混合模型全面领先。
- 所有模型都使用解析能量投影，因此全局热平衡误差接近数值零。该指标只验证总输入/排热平衡，不能替代局部通量、界面温降和弱形式残差。
- 当前数据仍是 Case1 内部的布局与网格泛化，不代表跨芯粒数量、跨封装、各向异性材料或接触热阻泛化。
